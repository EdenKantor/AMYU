# ADR 0010 — Hebrew default, language freedom and explicit identity

Status: accepted; lab bilingual UI implemented, onboarding/profile persistence deferred.

Hebrew is the first-run default and management UI supports RTL. Preferred language is a default for greetings/UI, while conversation follows the user's current Hebrew/English. The user chooses their preferred name/title and the companion's editable name. Explicit configuration overrides inference.

Consequence: no fixed character name or forced formal title. UI language does not restrict conversation language. Profiles can later be edited independently of learned memory.
