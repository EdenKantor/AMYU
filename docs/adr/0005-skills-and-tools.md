# ADR 0005 — Skills are distinct from tools

Status: accepted for a later milestone; not implemented.

A Skill defines a category-of-work procedure; a Tool is an executable operation. Skills declare tool/capability use and permission needs. Versioned manifests/playbooks are lazily loaded, provider independent and evaluation gated.

Consequence: instructional text cannot execute arbitrary code or bypass permissions. Skill improvement produces candidate revisions, evaluation and review instead of autonomous production-prompt edits. No registry UI or marketplace is part of Avatar Lab.
