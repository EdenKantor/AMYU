# Onboarding boundary — next milestone

Onboarding is not implemented in Avatar Lab. The lab language switch exists only for developer controls and defaults to Hebrew with RTL.

First launch will select Hebrew/English, ask for the user's preferred name and optional title, ask for the companion's editable personal name, offer warm optional personal context, and separately explain microphone/screen/camera capabilities. Persist setup before introducing the character. Then play an original short wake/introduction and greet with the configured name/language. No hard-coded companion name and no mandatory formal title.

Profiles remain editable, and a development reset command will return to first-run setup. Explicit profile preferences take precedence over inference. The future onboarding must never expose a companion before setup completion; the current development-only lab is not that product first-run experience.
