# AMYU development character

`amyu-developer.riv` is original temporary artwork generated by
`../../scripts/build-character.mjs`. It contains native Rive vector shapes,
gradients, cubic mouth vertices, and 23 numeric state-machine blend layers.
No community assets, downloaded artwork, images, external fonts, or audio are
included. This artwork was created for the AMYU project. The project owner
controls its rights and should select a distribution license before release.

Run `pnpm character:build` to reproduce the binary and its input manifest.
`pnpm test` runs the actual WASM decoder and checks input names, neutral
centering, gaze, blink, speech mouth transforms, and 30 simulated minutes of
state-machine advancement. Headless tests do not verify drawn pixels or replace
a 30-minute browser/WebView quality and resource-use acceptance run.
The file targets Rive runtime format 7.0 and is tested with
`@rive-app/canvas-advanced` 2.44.0. It is deliberately a small developer rig,
not the final AMYU character design or a general Rive export library.

Artboard and state machine: **AMYU Developer**.
See `rig-manifest.json` for the exact numeric input names and ranges.
The renderer introspects actual input names and types. Missing optional controls
and type mismatches are reported as `UNMAPPED` and skipped. Invalid files and
missing artboards produce recoverable load errors.

The state machine uses one continuous 1D blend layer per control. Semantic
state, emotion, local blinking, gestures, and speech energy are composed by
the renderer-independent director. The Rive adapter translates that physical
frame into numeric inputs; artwork does not contain application logic.

To replace it, supply a new asset URL and `RiveRigAdapter` to
`RiveAvatarRenderer.create`. Implement the adapter for the new state-machine
input names. No provider, conversation, or director code needs to change.
